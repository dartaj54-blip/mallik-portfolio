# Malik Taajdar – React Portfolio

Run locally:
1. Install Node.js 18+ from https://nodejs.org
2. In this folder run: `npm install`
3. Then: `npm run dev`  (opens at http://localhost:5173)

Build for hosting (Netlify / Vercel / GitHub Pages): `npm run build` → upload the `dist` folder.

Edit text, skills, projects and your contact email in `src/data.js`.
Photos live in `src/assets/` (hero.png = Home, about.png = About).
